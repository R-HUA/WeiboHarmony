# WeiboPura 隐私政策

**最后更新：2026 年 10 月 14 日**

**适用版本：WeiboPura 1.0.0**

WeiboPura 是面向 HarmonyOS 手机和平板的第三方微博客户端，与微博及其关联方无隶属关系。本政策说明应用在内容浏览、登录、搜索、互动和系统分享中的数据处理方式。

首次启动时，应用展示数据使用说明，由您主动选择是否同意。确认前不初始化微博登录凭据，也不启动微博内容请求。应用会在本机保存您的同意状态。

## 一、信息及用途

| 信息 | 来源与用途 | 保存及发送范围 |
| --- | --- | --- |
| 微博登录会话、账号标识 | 您在内嵌微博登录页完成登录后，应用读取网页登录会话，并向微博校验登录状态和账号身份；用于关注流、“我的”热搜分类及账户互动 | 验证成功的会话加密保存在本机；需要身份认证的请求会携带会话信息发送至微博 |
| 用户资料、微博、评论、回复、转发及点赞列表 | 从微博读取并展示昵称、头像、账号标识、正文、媒体、时间及互动信息 | 展示于应用；部分信息流内容保存在本机阅读缓存中 |
| 搜索词、专题查询词及榜单分类 | 用于搜索、联想、热搜分类和专题内容查询 | 发送至微博；查询状态和结果保留在当前运行会话内，不作为持久化搜索历史保存 |
| 点赞、关注等操作及其目标 | 执行您主动选择的点赞、取消点赞、关注或取消关注 | 将目标微博或用户标识与登录会话发送至微博 |
| 评论、回复和评论转发内容 | 执行您确认发送的评论、回复或评论转发 | 内容及对应微博、评论标识发送至微博；仅打开操作菜单不会提交 |
| 阅读位置及界面设置 | 恢复信息流阅读位置，保存主题、语言、字号、布局及同意状态等设置 | 保存在本机应用存储中 |
| 请求与错误诊断信息 | 定位加载、登录或互动失败 | 应用使用设备日志记录必要的错误、部分内容标识和加载数量；未接入独立的统计或崩溃上传服务 |

访问微博、登录网页及媒体资源时，服务提供方还会接收网络地址、浏览器或客户端请求头，以及完成服务所需的请求参数。微博推荐内容和“我的”榜单由微博服务提供。

应用不提供自动或批量的点赞、评论、转发、关注功能。需要登录的操作仅在您登录并主动操作后发起。

## 二、本地保存与清理

- **登录信息**：应用读取内嵌登录页的会话 Cookie，确认登录有效后，使用系统密钥能力加密保存于应用私有存储。应用不另行保存您输入的微博密码；登录页中的信息由微博网页处理，网页自身可保存 Cookie 等站点数据。
- **访客会话**：用于未登录内容访问的访客 Cookie 仅保存在应用进程内存中，不写入应用登录凭据存储。
- **阅读缓存**：信息流快照、分页信息和阅读位置保存在加密的本地数据库中，按账号或访客区分；每个账户缓存最多保留 500 条、7 天，随缓存维护清理。
- **设置**：界面偏好、同意状态及保存的目标用户标识保存在本机应用存储中。
- **退出登录**：退出会使当前会话失效，清除已保存的登录凭据和内嵌网页 Cookie，并尝试清理该账号阅读缓存。缓存清理失败可能留下本地阅读数据，应用会记录错误。

可在“我的 → 软件设置”退出登录。若需彻底移除本地应用数据，可使用系统提供的应用数据清理或卸载功能。退出本应用不会撤销已经提交到微博的评论、转发、点赞或关注；相关内容和关系需在微博服务中管理。

## 三、权限与系统交接

当前安装配置声明以下四项权限：

| 权限 | 用途或使用范围 |
| --- | --- |
| 网络访问 | 访问微博登录页、内容接口和媒体资源，以及提交您主动确认的互动 |
| 振动 | 支持交互中的触感反馈 |
| 手势检测 | 在系统支持时响应手势分享 |
| 后台运行 | 安装配置包含后台数据传输声明；当前微博浏览与互动流程不使用后台长时任务 |

图片保存通过系统安全控件，在您点击保存时取得本次操作授权；应用未声明持续读取或写入图库的权限。当前微博流程不申请通讯录、位置、相机或麦克风权限，也不提供签到通知。

您选择系统分享时，微博链接、标题、文本或预览图会交给 HarmonyOS 分享面板及您选定的接收应用。分享调用失败时，应用可能将链接复制到剪贴板；选择评论菜单中的“复制”也会将评论文字写入剪贴板。接收应用的数据处理由该应用负责。

## 四、外部服务

应用访问微博的移动站、桌面站、登录站及相关媒体服务，包括 `m.weibo.cn`、`weibo.com`、`passport.weibo.com` 和新浪、微博媒体域名。内嵌登录页由微博控制，其页面资源和登录方式遵循微博自身的服务规则。

应用未配置由本项目运营的用户数据收集服务器，不会将登录会话发送至本项目的自有服务器。微博接口请求、登录网页、媒体访问及您主动选择的分享接收方会处理完成相应功能所需的数据。

查看在线隐私政策或项目仓库时，会访问 GitHub；点击外站链接会打开相应网站。请同时留意这些服务自身的隐私说明。

## 五、您的选择

您可不登录而尝试使用公开内容访问；关注流、“我的”热搜分类及写入互动需要微博账号。微博可能因登录要求、验证码、限流或接口变化而限制部分内容访问。

您可退出登录、调整系统权限、清理本地应用数据，或停止使用应用。微博账号资料及已提交内容的查看、修改和删除需通过微博提供的渠道处理。
